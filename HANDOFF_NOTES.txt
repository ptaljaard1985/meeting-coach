WHAT IS IMPLEMENTED
- Browser-local parsing of speaker blocks, inline labels and attributed VTT/SRT; explicit adviser/client/observer roles and one-client/couple/other context; deterministic metrics and attribution/coverage gates.
- Bounded same-origin APIs with independent server validation, responsibility notice 2026-10-02.2, strict structured review validation and exact source-linked evidence. Server recalculates equal-weight overall excluding n/a; criteria verdicts are not an arithmetic category-score formula.
- Seven score panels, 24 criteria, five complete coaching takeaways, local optional title and client-side PDF download from the existing result. No regrading on download, browser persistence or recoverable meeting history.
- Synthetic offline preview with visibly hand-authored scores; arbitrary input is not graded in demo and the AI generator is disabled there.
- Production fail-closed Turnstile + Upstash shared Redis limiter: 30 model calls/UTC day, 12 calls/network/hour, concurrency 3 by default. Reserve every outbound attempt; no optimistic refunds. Includes duplicate submission IDs and expiring leases.
- Numerical analytics in mc:{analytics}:records and mc:{analytics}:index, separate from the expiring limiter keys. One record per accepted model request, updated for attempts/outcomes; sum returned correction usage, keep successful overall/seven category scores. Missing usage is marked incomplete; interrupted work may remain running. Writes are best effort, without content-bearing errors.
- Operator-only CSV export/summary and explicit deletion commands. ANALYTICS_ENABLED=false stops future collection, not existing retention; let active requests finish before deletion if no later writes are wanted. Exported CSV copies have a separate lifecycle.
- Consultant scoring guide: nine A4 pages, one per category plus introduction/method, matching PDF and editable Word. Scoring has not been calibrated or consultant-approved.

reference/crm/lib/scorecards/judge.ts + judge.test.ts
  Existing substantive prompt v1.4, Anthropic forced tool schema, validation, overall calculation and orchestration. Boundary worth preserving
The original feature judges adviser craft, not whether the advice was legally correct or financially suitable.
